# TaskManager - Gestión de Tareas

**Estudiante:** Edison Fabricio Oñate Cañar  
**Asignatura:** Programación de Sistemas Web 

## Descripción
Aplicación web interactiva desarrollada con JavaScript Vanilla (ES6+) para la gestión de tareas. Permite crear, editar, eliminar y marcar tareas como completadas, con filtros de búsqueda, ordenamiento y un Dashboard reactivo. Utiliza `localStorage` para funcionar de manera offline y consume la API pública de JSONPlaceholder.

## Tecnologías Utilizadas
* HTML5
* CSS3
* JavaScript (Vanilla, CustomEvents, Fetch API, LocalStorage)

## Cómo visualizar el proyecto
1. Clona el repositorio o descarga los archivos.
